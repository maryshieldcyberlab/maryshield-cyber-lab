Enterprise Cyber Lab

The MaryShield Cyber Lab is a fully virtualized enterprise cybersecurity environment designed to simulate real-world corporate networks. It provides hands-on experience with system administration, network security, threat detection, SIEM technologies, incident response, threat hunting, endpoint monitoring, and defensive security operations.

Enterprise Network Architecture

The architecture below illustrates the segmented MaryShield Cyber Lab environment, including the pfSense firewall, Windows and Linux systems, SIEM and XDR platforms, security-monitoring infrastructure, and authorized security-testing systems.

Overview

The laboratory consists of multiple virtual machines connected through segmented virtual networks using VMware Workstation Pro. Each system performs a specific enterprise function, allowing realistic security monitoring, controlled attack simulations, event correlation, and defensive investigation.

Monitoring and Logging

Windows systems generate Security Event Logs and Microsoft Sysmon telemetry that are forwarded to Splunk Enterprise for centralized log analysis, dashboards, alerting, and event correlation.

Wazuh XDR provides endpoint monitoring, file integrity monitoring, security analytics, and agent-based telemetry. Security Onion provides network visibility using Suricata IDS, Zeek metadata, Hunt, and packet analysis.

pfSense supplies firewall, routing, segmentation, and network-control telemetry. Together, these platforms provide layered visibility across identity, endpoint, network, firewall, and SIEM data sources.
