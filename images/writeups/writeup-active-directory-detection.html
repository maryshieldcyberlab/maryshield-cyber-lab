Executive Summary

This write-up documents an Active Directory security investigation involving authentication activity, account changes, PowerShell execution, and centralized SOC correlation.

Scenario

Controlled domain activity was generated to evaluate the visibility provided by Windows Security Events, Splunk Enterprise, Wazuh XDR, Security Onion, and Sysmon.

Key Windows Events

  • 4624 — Successful logon
  • 4625 — Failed logon
  • 4720 — Account creation
  • 4728 / 4732 — Group membership changes
  • 4768 / 4769 — Kerberos authentication activity

Findings

The investigation demonstrated the value of combining identity, endpoint, SIEM, and network telemetry when evaluating suspicious Active Directory behavior.

Recommendations

  • Enable detailed Windows auditing.
  • Monitor failed and successful authentication patterns.
  • Review privileged group membership.
  • Monitor PowerShell execution.
  • Maintain least privilege.
  • Centralize domain-controller logs.
  • Use account lockout controls where appropriate.

Lessons Learned

Active Directory investigations require strong identity context and careful correlation between authentication, administrative, and endpoint telemetry.
