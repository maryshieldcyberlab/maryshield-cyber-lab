Executive Summary

This write-up documents an endpoint investigation using Microsoft Sysmon telemetry. Process creation, command-line activity, network connections, file activity, registry changes, and PowerShell execution were reviewed and correlated with Splunk Enterprise and Wazuh XDR.

Telemetry Source

Microsoft Sysmon provided detailed Windows endpoint telemetry through the Sysmon Operational event channel.

Findings

Sysmon significantly increased endpoint visibility by providing detailed process, command-line, user, and network context that could be correlated across centralized monitoring platforms.

Recommendations

  • Maintain a tuned Sysmon configuration.
  • Collect process and command-line telemetry centrally.
  • Monitor PowerShell behavior.
  • Review parent-child process relationships.
  • Correlate endpoint and network telemetry.
  • Continuously tune detection logic.

Lessons Learned

Raw telemetry becomes significantly more useful when analysts correlate process context with user, network, and SIEM evidence.
