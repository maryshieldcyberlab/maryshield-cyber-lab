Cybersecurity Investigation Write-Ups

Overview

This section contains professional cybersecurity case-study write-ups developed from controlled exercises performed within the MaryShield Cyber Lab.

Each write-up documents the investigation process from initial detection through evidence analysis, event correlation, MITRE ATT&CK mapping, response actions, lessons learned, and security recommendations.

These case studies demonstrate practical SOC Analyst skills including SIEM analysis, endpoint investigation, network security monitoring, Active Directory security, threat hunting, incident response, detection engineering, and technical reporting.
