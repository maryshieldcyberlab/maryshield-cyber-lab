Executive Summary

This write-up documents a controlled incident response exercise performed within the MaryShield Cyber Lab. The investigation followed a structured workflow that included detection, triage, evidence collection, containment, eradication, recovery, and post-incident review.

Evidence was correlated across Splunk Enterprise, Wazuh XDR, Security Onion, pfSense, Windows Event Logs, and Sysmon.

Scenario

A simulated security incident was generated within the isolated lab environment to validate the ability of multiple defensive platforms to detect suspicious activity and support a coordinated response.

Environment

Platform Purpose
Splunk Enterprise SIEM search and event correlation
Wazuh XDR Endpoint monitoring and alert analysis
Security Onion Network security monitoring
pfSense Firewall evidence and containment
Windows / Sysmon Endpoint and authentication evidence

Detection

Evidence Collected

  • Splunk event searches
  • Wazuh endpoint alerts
  • Security Onion network telemetry
  • pfSense firewall logs
  • Windows Security Events
  • Sysmon process telemetry
  • Incident timestamps

Investigation

Endpoint, network, identity, and firewall evidence was correlated to determine the source, target, scope, and sequence of activity.

Incident Timeline

Containment

Network and endpoint controls were used to restrict the simulated activity and prevent additional impact.

Eradication

Test artifacts, vulnerable conditions, and temporary changes associated with the simulation were removed or reversed.

Recovery

Findings

Combining SIEM, endpoint, network, and firewall telemetry improved confidence in the investigation and supported a complete incident-response workflow.

Recommendations

  • Maintain centralized logging.
  • Continue endpoint monitoring.
  • Preserve network telemetry.
  • Maintain network segmentation.
  • Document containment procedures.
  • Review incident-response playbooks regularly.

Lessons Learned

The investigation reinforced the importance of evidence correlation, timestamp alignment, containment planning, and post-incident validation.
