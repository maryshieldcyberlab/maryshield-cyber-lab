Security Onion Enterprise Monitoring

Security Onion is an enterprise network security monitoring platform designed to provide comprehensive visibility into network traffic, detect malicious activity, and support threat hunting and incident response. Within the MaryShield Cyber Lab, Security Onion serves as the primary Network Detection and Response (NDR) platform by collecting and analyzing network telemetry from multiple systems.

The platform integrates several open-source security tools, including Suricata for intrusion detection, Zeek for network metadata analysis, Elastic Stack for log management and visualization, Fleet for endpoint management, and PCAP for full packet capture. Together, these components provide deep visibility into enterprise network activity and enable efficient investigation of security events.

This project demonstrates the deployment, configuration, monitoring, and integration of Security Onion with Splunk Enterprise, Wazuh XDR, Active Directory, Windows Server 2022, and Windows 11 clients. The result is a layered enterprise security architecture capable of detecting, correlating, and investigating simulated cyber attacks.

Executive Summary

Security Onion was deployed within the MaryShield Cyber Lab to provide enterprise network security monitoring, intrusion detection, packet capture, threat hunting, and centralized visibility into network activity. The platform integrates with Windows Server 2022, Active Directory, Windows 11 Enterprise, Splunk, Wazuh, Kali Linux, Ubuntu Server, and Metasploitable to detect and investigate simulated cyber attacks.

Project Objectives

  • Deploy Security Onion as a Network Security Monitoring (NSM) platform.
  • Capture and analyze network traffic.
  • Monitor IDS alerts generated by Suricata.
  • Perform threat hunting using Hunt.
  • Correlate network events with Splunk and Wazuh.
  • Investigate simulated attacks.

Installation

Security Onion was deployed as a dedicated virtual machine within VMware Workstation Pro. The platform was configured with separate management and monitoring interfaces to provide centralized network security monitoring for the MaryShield Cyber Lab.

Installation Configuration

  • Virtual Machine: Security Onion 2.x
  • Platform: VMware Workstation Pro
  • Operating System: Linux
  • Management Interface: VMNet1
  • Monitoring Interface: Connected to mirrored network traffic
  • Role: Standalone Manager
