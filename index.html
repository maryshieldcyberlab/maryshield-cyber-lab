About the MaryShield Cyber Lab

The MaryShield Cyber Lab is a multi-segment enterprise cybersecurity environment designed for security monitoring, threat detection, incident response, Active Directory security, network defense, endpoint analysis, and controlled security testing.

The environment integrates Windows, Linux, SIEM, XDR, network security monitoring, firewall, endpoint telemetry, and authorized offensive-security technologies to simulate realistic SOC operations.
