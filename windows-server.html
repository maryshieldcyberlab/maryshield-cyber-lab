Executive Summary

Windows Server 2022 serves as the core infrastructure platform for the MaryShield Cyber Lab. It provides centralized identity management, authentication, authorization, DNS, DHCP, and enterprise administration through Active Directory Domain Services.

Project Objectives

  • Deploy Windows Server 2022
  • Configure Active Directory Domain Services
  • Promote the server to a Domain Controller
  • Configure DNS
  • Configure DHCP
  • Create Organizational Units
  • Create enterprise users and groups
  • Join Windows 11 Enterprise to the domain
  • Implement Group Policy
  • Prepare infrastructure for enterprise security monitoring

Enterprise Architecture

Windows Server 2022 provides centralized authentication and identity services for enterprise clients connected to the MaryShield domain.

Windows Server Installation

Windows Server 2022 was installed as a virtual machine using VMware Workstation Pro. After installation, network settings were configured with a static IP address, computer name, and administrator credentials.

Windows Server Deployment Screenshots

The following screenshots document the deployment and configuration of Windows Server 2022 within the MaryShield Cyber Lab.

Active Directory Domain Services

Active Directory Domain Services (AD DS) was installed using Server Manager. The server was promoted to a Domain Controller for the maryshield.local domain.

DNS Configuration

The integrated DNS server provides name resolution for all domain-joined systems within the MaryShield Cyber Lab.

DHCP Configuration

DHCP was configured to automatically assign IP addresses to enterprise workstations while reserving static addresses for infrastructure servers.

Organizational Units

Organizational Units were created to logically separate Servers, Workstations, Users, Service Accounts, and Administrative Accounts.
