Splunk Enterprise SIEM

Executive Summary

This project documents the deployment and configuration of Splunk Enterprise within the MaryShield Cyber Lab. Splunk serves as the centralized Security Information and Event Management (SIEM) platform, collecting logs from Windows and Linux systems to support monitoring, detection, investigation, and threat hunting activities. The implementation demonstrates enterprise logging, endpoint visibility, security analytics, dashboard creation, and incident investigation techniques used by modern Security Operations Centers (SOC).

Project Objectives

  • Deploy Splunk Enterprise
  • Configure Universal Forwarders
  • Collect Windows Event Logs
  • Collect Sysmon Logs
  • Monitor Linux Logs
  • Create Security Dashboards
  • Build Detection Searches
  • Perform Threat Hunting

Installation

Splunk Enterprise was installed on an Ubuntu Server virtual machine within the Servers network segment. The service was configured to start automatically during system boot and listens for incoming Universal Forwarder connections.

Major Installation Tasks

  • Ubuntu Server deployed
  • Static IP configured
  • Splunk Enterprise installed
  • Splunk management interface enabled
  • Receiving port configured
  • Web interface verified

Universal Forwarders

Splunk Universal Forwarders were installed on Windows Server 2022 and Windows 11 Enterprise. These agents securely forward Windows Event Logs and Sysmon telemetry to the central Splunk Enterprise server for analysis.

Sysmon Integration

Microsoft Sysmon was deployed to provide enhanced endpoint visibility, including process creation, network connections, driver loading, registry modifications, and PowerShell execution events. These events significantly improve threat detection capabilities compared to standard Windows Event Logs.

Splunk Dashboards

The following dashboards were developed within the MaryShield Cyber Lab to monitor authentication events, endpoint telemetry, Windows security logs, network activity, and indicators of compromise.

SPL Query


index=windows (EventCode=4624 OR EventCode=4625)
| stats count by EventCode

Purpose: Monitor authentication activity to identify normal login behavior and detect suspicious authentication attempts.

SPL Query


index=windows EventCode=4625
| timechart span=1h count

Purpose: Identify repeated authentication failures that may represent malicious activity.

SPL Query


index=windows EventCode=4104
| stats count by Computer

Purpose: Detect suspicious PowerShell usage that could indicate post-exploitation or malicious scripting.

SPL Query


index=sysmon EventCode=1
| top Image

Purpose: Identify unusual processes that may indicate malware or unauthorized software execution.

SPL Query


index=sysmon EventCode=3
| top DestinationIp

Purpose: Monitor network communications to identify suspicious outbound connections and potential command-and-control activity.

SPL Query


index=windows EventCode=4720
| table _time Computer TargetUserName SubjectUserName

Purpose: Detect unauthorized account creation that may indicate persistence or privilege escalation.

SPL Query


index=windows EventCode=4732
| table _time TargetUserName MemberName

Purpose: Detect privilege escalation and unauthorized administrative access.

SPL Query


index=*
| stats count

Purpose: Provide analysts with a high-level operational view of the environment for continuous monitoring and rapid incident response.

Common SPL Searches

The following SPL (Search Processing Language) queries were used to monitor security events within the MaryShield Cyber Lab.

Failed Login Attempts (Event ID 4625)



index=windows EventCode=4625

Displays failed Windows logon attempts.

Successful Logins (Event ID 4624)



index=windows EventCode=4624

Shows successful user authentications.

New User Accounts (Event ID 4720)



index=windows EventCode=4720

Detects creation of new user accounts.

New Local Administrators



index=windows EventCode=4732

Detects users added to privileged groups.

PowerShell Activity



index=windows EventCode=4104

Monitors PowerShell execution.

Sysmon Process Creation



index=sysmon EventCode=1

Displays newly created processes.

Network Connections



index=sysmon EventCode=3

Shows outbound network connections.
